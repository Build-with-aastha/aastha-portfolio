AASTHA SHARMA PORTFOLIO WEBSITE

Files:
- index.html: Main portfolio website
- resume.html: Resume preview page with Open PDF and Download PDF actions
- assets/Aastha_Sharma_Resume.pdf: Updated two-page resume PDF

IMPORTANT: Keep the index.html, resume.html, README.txt and the complete assets folder together in the repository root.

To publish/update using GitHub Pages:
1. Extract this ZIP on your phone/computer.
2. Open your public GitHub repository for the portfolio.
3. Upload/replace index.html, resume.html, README.txt and the assets folder contents at the repository root (not inside another folder).
4. Commit the changes. If GitHub Pages is already enabled for main / root, the public site updates automatically after deployment.

The View Resume links open resume.html. The resume page shows a PDF preview and also provides Open PDF and Download PDF links. Some mobile browsers may not render embedded PDF previews; use Open PDF in that case.
